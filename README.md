## 🚀 Some Cool Projects I've Built

Here are a few I'm proud of. Most are live, so feel free to try them:

### 1. pqc
A pure-JavaScript library implementing the NIST post-quantum cryptography standards (ML-KEM, ML-DSA, SLH-DSA). No native dependencies, and fast enough to use straight from the browser.
- **Tech:** JavaScript, NIST FIPS 203/204/205, npm
- **Links:** [npm Package](https://www.npmjs.com/package/pqc)

### 2. PQC-Vizz
An interactive visualizer for post-quantum algorithms. It runs the real pqc library in the browser, so you can watch each step happen.
- **Tech:** Next.js, TypeScript, SVG
- **Links:** [Live Demo](https://pqc.nithinram.com/) | [GitHub](https://github.com/nithinramkalava/pqc-vizz)

### 3. PC Building Assistant
Built this because I love building PCs and wanted to help others do the same. It uses ML to rank components and a database to keep every build compatible, with an LLM chat on top.
- **Tech:** Python, Next.js, PostgreSQL, TypeScript, Ollama
- **Links:** [Live Demo](https://pc.nithinram.com/) | [GitHub](https://github.com/nithinramkalava/build-your-pc)

### 4. CareerPath Navigator
Helps rural students explore career paths through interactive visualizations, and it works even on slow connections.
- **Tech:** Next.js, React, TypeScript, Tailwind CSS
- **Links:** [Live Demo](https://careerpath-nav.nithinram.com/) | [GitHub](https://github.com/nithinramkalava/CareerPath-Navigator)
